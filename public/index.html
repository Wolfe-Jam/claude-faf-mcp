Install

Claude Desktop — one click

Download claude-faf-mcp-5.22.1.mcpb and open it. The extension runs the server bundled inside it, with the Node that Claude Desktop provides.

Claude Desktop — config

Add to claude_desktop_config.json, then restart Claude Desktop:

{
  "mcpServers": {
    "faf": {
      "command": "npx",
      "args": [
        "-y",
        "claude-faf-mcp"
      ]
    }
  }
}

Claude Code

claude mcp add faf -- npx -y claude-faf-mcp

The npx config and the SessionStart hook are not pinned: they run the latest claude-faf-mcp. Needs Node 22 or later.
